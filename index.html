📖 ヘルプ・使い方

初めての方は「はじめての使い方」から。画像付きマニュアルとPDFも用意しています。

まずはこの順番で使ってみましょう

シェアリスコアは、演奏できる曲を自分のリストにまとめ、仲間と「何を演奏するか」を決めるサービスです。楽曲を探すだけなら、ログインせずに始められます。

ひとりで準備する：ログイン → 曲を探す → マイリストへ登録。
仲間と使う：ルームを作成・参加 → 曲を予約 → 演奏確定 → 完了。

  1. Googleでログインします。マイリストを保存する場合は、画面左下の「Googleでログイン」を選びます。
  2. 演奏できる曲を1曲探します。「全曲一覧」を開き、上部の検索欄へ曲名やアーティスト名を入力します。
  3. 自分のリストへ追加します。曲の「＋登録」を選び、「マイリスト」でKeyと担当パートを設定します。
  4. 仲間のルームへ参加します。主催者のリンクを開くか、「ルーム」から作成・参加します。
  5. 演奏の順番を決めます。候補を予約し、演奏する曲を確定、終わった曲を完了にします。

完了の目安：最初の1曲がマイリストに入り、仲間と演奏候補を確認できれば準備完了です。

ログインして、自分の名前を設定する

準備：個人のマイリストやフレンド機能にはGoogleログインを使います。ゲストは共有URLからルームに参加できますが、個人リストの保存・共有にはログインが必要です。

  1. 左メニュー下部の「Googleでログイン」を選び、Googleの画面でアカウントを選択します。スマートフォンは先に「☰」でメニューを開きます。
  2. ログイン後、左上のアカウント表示を選んで「アカウント設定」を開きます。
  3. 「ユーザー名（セッション用）」に仲間が分かる名前を入力し、「変更」を選びます。
  4. 基本担当パートを選び、「保存」を選びます。これは今後新たに登録する曲に適用され、登録済みの曲は変更されません。

完了の目安：「ゲスト利用中」からログイン中の表示に変わり、ユーザー名を確認できれば設定できています。

ログイン画面が開かないときは、ブラウザーがポップアップをブロックしていないか確認します。共有端末では利用後にログアウトしてください。

全曲一覧から演奏したい曲を探す

準備：曲名やアーティスト名が分かれば検索できます。閲覧のみならログインは不要です。

  1. 左メニューの「全曲一覧」を選びます。
  2. 上部の検索欄に曲名、アーティスト、アニメ名などを入力します。検索語を短くすると候補を広く探せます。
  3. 必要に応じてジャンルボタンを選びます。絞り込みを外すときは検索語を消し、ジャンルを「すべて」に戻します。
  4. 曲名を選んで詳細情報を確認します。ChordWikiのリンクがある曲はコード譜を開けます。
  5. 自分が演奏できる曲は「＋登録」でマイリストへ追加します（Googleログインが必要です）。

完了の目安：目的の曲を見つけ、曲名・アーティスト・詳細を確認できれば完了です。

「Key一括リセット」は検索の解除ではありません。登録済みの保存Keyも原曲の0へ戻るため、検索し直したいときは検索欄とジャンルを操作してください。

演奏できる曲と、自分の設定を保存する

準備：Googleでログインし、全曲一覧から演奏できる曲を登録してください。「マイリスト」は自分用の楽曲リストです。

  1. 左メニューの「マイリスト」を選びます。登録した曲があることを確認します。
  2. 曲ごとのKeyを設定します。0は原曲、+1は半音上、-1は半音下です。例：歌いやすく2半音下げるなら-2を選びます。
  3. 担当パートを選びます。ボーカル、ギターなど、演奏できるパートを複数選べます。
  4. 変更後は保存失敗の通知が出ていないことを確認します。通知が出た場合は通信状況を確認し、「再試行」を選びます。

完了の目安：登録曲ごとのKeyと担当パートが、自分の希望する設定になっていれば完了です。

複数の曲をまとめて編集する

  1. 対象の曲をチェックします。「表示中を選択」は現在のページの曲を選びます。
  2. 一括編集欄でKeyや担当パート、パートON／OFFを指定します。
  3. 「選択曲に適用」を選び、対象曲の設定を確認します。

「選択曲を削除」は自分のマイリストから削除します。全曲一覧の楽曲自体は削除されません。削除前に選択した曲を確認してください。

Excel・スプレッドシートの曲をまとめて登録する

準備：Googleでログインし、曲名・アーティストなどが並んだ表を用意します。文章ではなく、2列以上のセル範囲をコピーします。

  1. ExcelやGoogleスプレッドシートで曲名・アーティストのセル範囲を選択し、コピーします。URLとKeyの列は必要に応じて用意します。
  2. マイリストの「貼り付けからのマイリスト一括登録」を開き、「クリップボードの表を読み取る」を選びます。
  3. 列を「曲名」「アーティスト」「URL」「Key」「使用しない」に割り当て、「この列設定で確定」を選びます。
  4. 解析結果で一致曲と未一致曲を確認し、「一致曲の登録内容を確認」へ進みます。
  5. Keyなどの内容を確認し、「確定して登録」を選びます。結果の件数を確認して「完了」を選びます。

完了の目安：登録結果の件数を確認し、マイリストに対象曲が表示されれば完了です。

未一致・エラー・重複行は登録されません。URLがない場合も曲名とアーティストから照合し、大文字・小文字、半角・全角、スペースや句読点の違いを吸収します。複数候補がある行は登録先を選択するか、その行を除外してください。既に登録した曲はKeyが更新され、担当パートは維持されます。確定前に内容を確認してください。

Keyが空欄の場合・未一致の曲の扱い

Keyが空欄ならURLのkeyを使い、どちらもなければ0（原曲）になります。表のKeyとURLのKeyが異なる場合は確認画面で選びます。未一致の曲は新規楽曲登録申請へ進めますが、管理者承認まで全曲一覧には反映されません。

画面ごとに確認したいとき

マイリストの「クリップボードの使い方を見る」には、コピー・列設定・解析・確認・結果を画像付きで説明した5ページのガイドがあります。

仲間とセットリストを共有する

ルームとは：参加者で候補曲や演奏状況を共有する場所です。主催者は作成、参加者は共有リンクまたはルームIDから入室します。

自分が主催するとき

  1. 左メニューの「ルーム」を開き、「ルームを作成」を選びます。
  2. 確認画面の「ルームを作成」で確定します。ルームIDは自動で発行されます。
  3. 入室後、ルーム接続表示の右側の「ルームURLをコピー」からルームURLをコピーし、仲間へ送ります。

仲間のルームに参加するとき

  1. 共有されたルームURLを開きます。IDで参加する場合は「ルーム」→「ルームに入る」を選びます。
  2. 主催者から受け取ったルームIDを入力し、「入室する」を選びます。
  3. 入室後、ユーザー名と参加者を確認します。個人マイリストを共有する場合はGoogleログインを使います。

完了の目安：目的のルームに入り、参加者と同じ演奏候補を確認できれば完了です。

IDが分からないときは主催者に確認します。終了時はルームの「退室」から退出します。

演奏する曲を決め、進行を記録する

準備：ルームへ入室してください。演奏状況は参加者で共有されるため、相談しながら操作します。

  1. 全曲一覧や共通曲から演奏候補を探し、予約します。共通曲では、選んだ参加者が全員登録している曲を探せます。
  2. 右側のセッション進行バーで「予約」を確認します。演奏すると決めた曲を確定すると「演奏確定」へ移動します。
  3. 演奏が終わった曲を完了にすると、「完了」へ移動します。

完了の目安：演奏した曲が「完了」に並び、セットリストが残れば完了です。

間違えたとき・複数曲を操作するとき

  • 「戻す」は演奏確定から予約、完了から演奏確定へ戻します。
  • 曲にチェックを付けると、選んだ曲をまとめて操作できます。対象曲と移動先を確認してください。
  • 予約・演奏確定の「削除」は候補を取り消す操作です。マイリストから曲を削除する操作とは別です。

演奏した曲を画像にする

完了欄の「画像保存」からセットリスト画像の作成画面を開けます。画面の案内に従って保存してください。

スマートフォンや狭い画面では進行バーが折りたたまれます。開閉ボタンで表示し、「予約」「確定」「完了」を切り替えて確認します。

OBS配信画面を編集する

  1. ルーム参加中に「OBS配信画面設定」を開きます。
  2. テーマ・配信者・説明・参加者の表示名と担当パートを設定し、プレビューを確認します。
  3. はみ出し警告がある名前・パートを短くして「保存してOBSに反映」を押します。
  4. 「URLをコピー」からOBSのブラウザソースへ設定し、幅1920・高さ1080にします。旧カスタムCSSは削除してください。

完了曲を右バーの並び順で表示します。曲名・アーティスト名は全文を折り返し、一覧が長い場合は縦に自動スクロールします。配信表示用の名前はルーム参加名を変更しません。

仲間の公開マイリストと共通曲を探す

準備：Googleでログインし、相手のフレンドコードを教えてもらいます。

  1. 左メニューの「フレンド」を選びます。自分のフレンドコードは「コピー」で相手に共有できます。
  2. 「フレンドコードで探す」に相手のコードを入力し、「検索」を選びます。
  3. 検索結果から相手の公開マイリストを開きます。曲名・ジャンルなどで絞り込めます。
  4. 「自分との共通曲のみ」にチェックすると、一緒に演奏できる曲を探せます。「お気に入りアーティスト」も確認できます。

完了の目安：相手の公開リストを開き、一緒に演奏したい曲を確認できれば完了です。

相手のデータを直接変更することはできません。リストがまだ表示されない場合は、相手にログインとマイリストの保存を確認してもらってください。

全曲一覧にない楽曲を登録申請する

準備：同じ曲が登録済みでないか検索し、原曲のChordWiki URLを用意します。

  1. 左メニューの「新規楽曲追加」を選びます。
  2. 曲名・アーティスト名・ChordWiki URLなど、画面で必須と表示された項目を入力します。URLは原曲ページのものを使います。
  3. 表記や内容を確認し、「管理者へ登録申請」を選びます。
  4. 画面の送信結果を確認します。楽曲は管理者の確認・承認後に全曲一覧へ反映されます。

完了の目安：申請の送信結果を確認できれば、この操作は完了です。送信直後に全曲一覧へ表示されなくても、承認待ちの場合があります。

「全曲一覧への楽曲申請」と「自分のマイリストへの登録」は別の操作です。公開された後、演奏できる曲を自分のマイリストへ登録してください。

見やすい画面に調整する

  1. 左メニューの「設定」を開きます。
  2. UIカラーテーマでダーク／ライトを選びます。
  3. 言語とフォントを選び、読みやすい表示に調整します。フォントの見え方は端末によって異なります。
  4. 最新の情報が表示されないときは、「最新情報を再読み込み」を選びます。

完了の目安：文字と背景が見やすい状態になれば設定完了です。

ユーザー名と基本担当パートは「設定」ではなく、左上のアカウント表示から開く「アカウント設定」で変更します。

スマートフォンのメニューと画面の見方

  1. トップ画面左上の「☰」をタップしてメニューを開きます。
  2. 「全曲一覧」「マイリスト」「ルーム」など、使いたい項目を選びます。Googleログインの入口はメニューの下部にあります。
  3. ヘルプでは上部の「読みたい項目」を選ぶと、各操作の説明へ切り替わります。本文を上下にスクロールして読めます。
  4. 画像をタップすると別タブで拡大できます。読み終わったらサイトのタブへ戻って操作を続けます。

完了の目安：メニューから目的の画面へ進めれば準備完了です。

よくあるつまずきと確認する場所

マイリストを開けない・登録できない

Googleログインが必要です。「ゲスト利用中」の表示なら、メニュー下部からログインしてください。ポップアップをブロックしていないかも確認します。

曲が見つからない

検索語を短くする、曲名とアーティスト名を別々に試す、ジャンルを「すべて」に戻す順で確認します。登録済み曲の除外が有効なら解除してください。未登録なら「新規楽曲追加」から申請します。

マイリストの変更を保存できない

通信状況を確認し、保存失敗の通知の「再試行」を選びます。保存できたことを確認してから画面を閉じてください。

ルームに入れない

主催者から受け取ったURLやIDを確認します。別のルームに入っていないか、入力に余分な空白がないかも確認してください。

表から一括登録しても曲が増えない

解析結果と登録結果を確認してください。未一致・エラー・重複行は登録されません。曲名・アーティストの列設定と表記を見直します。未登録の楽曲申請は、管理者の承認が必要です。

画面の情報が古い・更新されない

「設定」→「最新情報を再読み込み」を試し、通信状況を確認します。共同操作では参加者に同じルームへ入っているかも確認してください。

OBSの配色が変わらない

「OBS配信画面設定」で保存し、現在のルームと配信者の専用URLをOBSに設定してください。幅1920・高さ1080にし、旧カスタムCSSを削除します。

画面を見ながら読む・PDFで保存する

トップ、検索、ルーム、設定などを14枚の画面画像で説明した、全16ページのマニュアルです。別タブで読むか、PDFを保存して確認できます。

画像付きマニュアルを読む（別タブ）PDFを開く（16ページ）PDFをダウンロード

このマニュアルは試作版です。2026年10月13日作成。楽曲一覧の画像には説明用サンプルを使っています。実際の画面と異なる場合があります。ログイン後の保存やルーム同期、OBSでの実表示は未検証で、対象の章に注記しています。

このヘルプの読み方

初めての方は「01 はじめての使い方」から順に進めてください。各項目は準備、操作手順、完了の目安をまとめています。迷ったら「13 困ったとき」から状況に合う項目を確認できます。

完了の目安：使いたい操作の説明を開ける、またはPDFを保存できれば完了です。

📋 貼り付けからマイリスト一括登録

Excel・スプレッドシートのセル範囲をコピーして、そのまま貼り付けできます。貼り付け後、列ごとに「曲名・アーティスト・URL（任意）・Key・使用しない」を選んでください。表形式のみ対応しています。

URLを省略しても曲名・アーティスト名から照合します。大文字・小文字、半角・全角、スペースや句読点などの表記ゆれを吸収し、複数候補がある行は登録先を選択します。Keyが未記載ならURLのkeyを使い、両方未記載なら0（原曲）です。既存マイリスト曲はKeyを更新し、担当パートは維持します。マスター側のアーティストが空欄で、曲名＋ChordWiki URLが一意に一致した場合は、貼り付けたアーティスト名を管理者へ補完申請します。承認までは公開マスターを変更しません。

Excel・スプレッドシートで2列以上をコピーし、「クリップボードの表を読み取る」を押してください。

📊 クリップボードの列を設定

各列を「曲名・アーティスト・URL・Key・使用しない」に割り当ててください。最初の5行を表示しています。

未一致の曲は「新規楽曲登録申請」から曲名・アーティストを引き継げます。ChordWiki原曲URLと必須項目を確認して申請してください。管理者承認までは公開マスターへ反映されません。

曲名とアーティストの列が逆になっている可能性があります。列を入れ替えて再解析できます。

✏️ クリップボードの使い方

Excel・スプレッドシートからの一括登録を5ページで説明します。

① スプレッドシートからコピペ

曲名・アーティスト・コードWiki・Key などの列を含むセル範囲を、表のままコピーします。
Key列について：原曲を0として半音単位で指定できます（例：+3、-2）。指定したKeyはマイリストに保存され、ChordWikiを開く際にはそのKeyで自動移調したURLが使用されます。

② コピペした情報のヘッダーを指定

「📋 クリップボードの表を読み取る」を押すと列設定ダイアログが開きます。各列を 曲名 / アーティスト / URL（任意） / Key（任意） / 使用しない に割り当て、「✅ この列設定で確定」 を押します。

③ 解析結果を確認

解析結果ダイアログでは、先頭に 解析曲数｜一致曲数｜Key変更数｜エラー・未一致曲数 が表示されます。

  • 緑：楽曲データ一致
  • 赤：楽曲未登録（楽曲情報の新規登録可能）
  • Key変更数：既にマイリストにある同一曲で、登録済みKeyと今回のKeyが異なる曲数

④ 確認して登録

解析結果で 「✅ 一致曲の登録内容を確認」 を押すと、一括登録確認ダイアログが開きます。内容を確認して 「✅ 確定して登録」 を押すと、データへ保存されます。

⑤ 登録結果表示で完了

登録が終わると結果ダイアログが表示されます。新規マイリスト登録数 / Key更新数 / 登録対象外数 を確認して完了です。
