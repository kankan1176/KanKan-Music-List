# カテゴリによる楽曲の絞り込み

上部には「すべて」と J-POP・アニソン・ボカロ・K-POP・洋楽を表示します。J-POP/K-POP/洋楽はgenre1、アニソン/ボカロはgenre2から判定します。J-POPからアニソン・ボカロを除外する新ルールは適用していません。

- 音楽ジャンル：genre6（全カテゴリ）
- ボカロ別：vocal_synths（ボカロ）
- 発売・公開年：release_year（全カテゴリ。登録されている年から選択）
- 放送・公開年：anime_year（アニソン。西暦4桁、複数は「、」区切り）
- 掲載媒体・関連作品：genre5（アニソン）

カテゴリを変えると下位条件をリセットします。同じカテゴリ内で選んだ条件はANDです。音楽ジャンル・掲載媒体・ボカロ別は公開したソートマスタの項目順で表示し、該当曲がなくても選択できます。年代は登録済みの年から作ります。年代が未登録の間は選択欄を無効にします。発売年をアニメの放送・公開年として推定しません。

全曲一覧は順序付きの100件以下の取得と索引の交差でページを作ります。ルーム・自分のマイリスト・共有マイリストにも同じ分類処理を使用します。検索用データの切替を監視し、削除済みの古い索引を使い続けないようにしています。

スプレッドシートの列位置ではなくヘッダー名を基準に扱います。シートの編集だけで本番DBが自動同期される仕組みはありません。編集後は、IDを維持してマスターを反映し、検索インデックスを更新してください。分類の移行処理は他の楽曲項目・個人の登録・ルームを変更しません。公開リポジトリにマスターCSV/JSONを平文で追加しないでください。


右上の検索窓は全曲マスターを対象にします。入力時にカテゴリ・音楽ジャンル・歌唱者・アーティスト・登録済み除外を解除し、ルーム内では全曲一覧へ切り替えます。検索インデックスと候補の照合は分類6項目・vocal_synths・release_year・anime_yearを含みます。独立したマイリストページの検索はそのリスト内です。

正本ブックの別タブ「ソートマスタ」に既定の73項目（音楽12・掲載媒体13・ボカロ別48）を管理します。グループ名は管理用で、画面見出しとして表示しません。本体はこのタブから生成した sort-master.js の公開スナップショットを使用します。表を編集した後はスナップショットの更新・公開が必要です。表には表示順・別名照合・対象カテゴリ・有効フラグを持たせています。同名歌唱者が複数ソフトにある場合は別行を保持し、曲別の使用ソフトを名前から推定しません。

別名は同じ項目内でOR、別フィールドの条件はANDです。例：GUMI（Megpoid）はGUMI・Megpoid等、週刊少年ジャンプはジャンプも照合します。サーバー側も別名ごとの投稿を和集合にした後、フィールドを交差させ、1回100件以下の読み込みと重複のない100曲ページを維持します。別名による検索時に、元の楽曲分類や個人リストを書き換えることはありません。

2026-10-24：正本は19列です。M release_year / N anime_year / O tieup。イメージソングを含む関連作品年を保持し、年をまたぐ期は「、」で複数年を保存します。年条件は複数年のいずれかに一致、異なるフィールド同士はANDです。検索・共有投影・所有者キャッシュにも両年を含めます。全文CSVを列位置で読み替えず、正本ヘッダーとIDを検証してから本番へ反映します。本番だけの追加曲と、取得後に管理画面で更新された曲は保持します。

検索中に検索用データが切り替わった場合も、古い検索キーを破棄して同じ検索語で先頭ページを取り直します。
