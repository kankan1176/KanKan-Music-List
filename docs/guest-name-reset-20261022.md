# 2026年10月22日の全ゲスト参加名リセット

対象は全ルームのゲスト。Googleログインユーザーの表示名、マイリスト、楽曲、ルームの曲順・設定は変更しません。

- ブラウザでは匿名ユーザーだけに一度の移行を実施し、読込前から保存されていた `kankan_username` を削除します。ルーム内では匿名UID先頭5文字の既定名を表示します。
- ブラウザに実行済み印を残し、リセット後に改めて設定した名前は消しません。ページを開いてから新たに設定された名前も保存値の比較で保持します。
- 古い管理者の名前変更命令と今回の旧クライアント向け命令が、削除した保存名を復元しないよう抑制します。以後の新しい名前変更命令は有効です。
- 実行用GitHub Actionsは既存のサービスアカウントでゲスト候補のAuthenticationプロバイダーを確認してから処理します。Google等のプロバイダーを持つUID、公開プロフィール・アカウント登録済みUIDは除外します。
- 既存ゲストには個別の名前変更指示を送り、接続中の旧クライアントも既定名へ更新します。同時に、トランザクションで既存ルームのゲスト参加名だけを変更します。削除済みの参加者を再作成しません。
- 未接続・旧ページの端末では次回アクセスまたは再読み込み時に保存名の削除を反映します。
- 実行状況は `maintenanceOperations/guest-name-reset-20261022-v1` に記録し、成功済みの再実行では名前を再変更しません。途中失敗時は自動再実行せず確認を要求します。
- 設定ルール・課金プラン・Cloud Functions・Firebase Authenticationのアカウント自体は変更しません。処理ログに参加名・メールアドレス・資格情報を出しません。

検証: `node scripts/check-guest-name-reset.cjs`。ゲスト選別、Google保護、競合を考慮した参加者更新、旧命令の無効化、名前再設定の保持、実行済みの冪等性を合成データで検査します。ブラウザでも匿名ゲストの保存名削除とGoogleの名前維持を検証します。
