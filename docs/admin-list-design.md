# 管理者によるマイリストUI編集

管理者ページの「ユーザー操作」でGoogleログインユーザーの「マイリストUI編集」を押します。対象ユーザー名・UIDを確認し、タイトル、テーマ、各色、JPEG背景画像、背景の濃さをプレビューして「設定を保存」を押してください。

本人と同じデザイン形式・画像変換・プレビューを使用します。背景は1920×1080 JPEGに変換し、既存の容量制限内に保存します。既存画像は置き換え、または削除できます。

デザインの編集範囲は `userListShares/<uid>/appearance` と背景画像・背景バージョンです。公開中の共有ページはデザイン項目だけを一括更新します。デザイン保存では公開状態、共有トークン、Key・担当パートの公開設定、登録曲、公開ページの楽曲・所有者名は変更しません。共有設定が未作成の場合は非公開・Key／パート非公開の設定を作成します。自動で公開しません。

保存前に設定と背景を再取得し、読み込み時から変わっていれば保存を止めて再読み込みを案内します。保存は一括更新です。保存直前に別画面で共有URLが変更されたり公開停止された場合も、古い公開ページへの更新は権限ルールで拒否されます。同じデザイン項目へ同時に保存した場合は、最後の保存が有効です。

Google認証かつ `/admins/<uid> = true` の管理者だけに、選択したアカウントのデザイン設定・背景の読み書きを許可します。一般ユーザー・匿名ユーザー・未認証ユーザーの他人への編集は拒否します。個人設定全体の閲覧権限や、他人の登録済み楽曲の編集権限は付与しません。公開状態は後述の明示的な切り替え操作で変更します。既存の本人編集は維持します。

ルールは「Apply free admin control rules」で既存テストと `test-admin-list-design.cjs` が成功してから適用します。本番ユーザーの設定をテスト目的で変更しません。追加の課金サービスは使用しません。

## 管理者による公開・非公開

編集画面の「非公開：公開する」／「公開中：非公開にする」で切り替えます。確認には対象ユーザーを表示します。切り替えには保存済みデザインを使用し、未保存の編集は確認後に破棄します。

公開時は最新の登録済み楽曲と公開プロフィール名から共有スナップショットを作成し、既存のKey／担当パート公開設定を守ります。初回公開は両方非公開で開始します。楽曲収集中に元データが変わった場合は保存を止めて再確認を案内します。

非公開時は共有ページを予約済み状態に置き換え、公開画像とプロフィール側の共有導線を同時に除去します。本人用のデザイン・画像・登録曲・共有トークンは維持し、再公開時に同じURLと背景を復元します。すでに閲覧者が保存したデータや画像を回収する機能ではありません。

Google認証の管理者だけに対象ユーザーの公開状態操作と公開・再開時の共有スナップショット作成を許可します。公開中の楽曲を管理者が直接編集する権限や、Key／担当パート公開設定を変更する権限は追加しません。各公開操作は対象ユーザー単位であり、一括公開は行いません。
