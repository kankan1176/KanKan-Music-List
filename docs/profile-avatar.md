# プロフィールアイコン

「アカウント設定」からGoogleログイン本人が画像選択 → 400×400 pxの中央正方形切り抜きプレビュー → 保存を行います。削除は確認後に実行します。JPG/PNG/GIF入力は2 MiBまで、GIFは静止画、透明部分は白背景。入力画像の元データは保存せず、400px JPEG（data URL最大100,000文字）のみRealtime DatabaseのuserAvatars/UIDに保存します。課金プラン、Cloud Storage、Functionsへの変更はありません。

アイコンは公開プロフィール用である旨を選択前に表示します。UID単位の読み取りを公開し、一覧読み取りは許可しません。作成・置換・削除はGoogle認証済み本人に限定し、管理者による代理変更も許可しません。ユーザーデータや表示名には変更を加えません。現在はアカウント設定画面と左上アカウント表示へ反映します。OBS配信画面にも反映されます。他の一般参加者一覧への表示は変更していません。

通信失敗時はプレビューを残して再保存できます。ログイン切り替え時に購読・プレビューを破棄し、以前のアカウントの非同期応答は反映しません。日本語・英語・韓国語・繁体字に対応します。

検証: PC/モバイルの実際の設定画面CSSにて、画像変換・保存前プレビュー・削除・無効ファイル・通信失敗・ゲスト・言語変更を模擬Firebaseで確認。CIのDatabaseエミュレーターで本人・他人・ゲスト・管理者・未認証の権限と保存形式を検証してから本番ルールを反映します。
