# 翻訳補完の調査記録（2026-10-13）

対象は index.html の言語切り替え（日本語・英語・韓国語・繁体字中国語）と、同画面から開く機能です。

| 発見箇所 | 修正 |
| --- | --- |
| 14項目のヘルプ | 本文・目次・画像説明・入力案内を翻訳。強調タグで分断された文は文章全体で翻訳し、日本語に戻すと元の強調を復元 |
| トップ・更新情報・ナビゲーション | 新機能のお知らせ、メニュー、読み上げ用ラベルを追加 |
| ルーム・参加履歴・セッション進行 | 入室、削除済みルーム、選択曲操作、件数、完了・失敗メッセージを補完 |
| セットリスト画像保存 | 設定欄、背景・配置の選択肢、説明、状態表示と画像内の固定見出しを翻訳 |
| マイリスト・フレンド・楽曲編集 | 操作説明、空状態、保存確認、エラー、選択件数を補完 |
| クリップボード | 列設定、解析結果、登録確認、結果、5ページのガイドを補完 |
| 新規楽曲申請 | 翻訳側に残っていた即時公開の説明を、管理者承認後に公開する現在の仕様へ修正 |
| 利用規約・プライバシー | 日本語本文の条件・例外を維持して3言語を用意 |

翻訳辞書は ui-translations.js に配置。日本語の元文をキーとし、件数・名前等はテンプレート変数で保持します。固有名詞・楽曲情報・ユーザーの入力値・データベースのキーは翻訳対象にしません。選択肢は表示だけを翻訳し、値は元のまま保持します。

既存の日本語スクリーンショット・画像付きマニュアル・PDF自体は変更していません。他言語のリンクには日本語資料であることを明記しました。別ページの admin.html / obs.html に新しい言語選択UIを追加する変更は含みません。

## 検証

Playwright と Chromium が利用できる環境で `node scripts/check-translations.cjs` を実行します。必要に応じて CHROMIUM_PATH で実行ファイルを指定できます。

- インラインJavaScriptの構文と3言語辞書の変数整合性
- 各言語の固定文言・入力ヒント・代替テキストの翻訳漏れ
- 14項目のヘルプをPC幅・スマートフォン幅で確認
- 日本語への復元（強調表示含む）
- 後から追加されたダイアログ・状態表示の翻訳
- 曲名、アーティスト名、選択肢の保存値の保持
- 削除確認メッセージと21曲・2枚の画像プレビューの言語切り替え

検証では認証とルームデータをモック化し、本番Firebaseへの書き込みは行いません。
