# OBS背景透過と本人欄の中央配置

テーマ選択の下に「背景を透過する」チェックボックスを追加しました。ダーク・ライト共通の設定で、保存するとOBSへ反映されます。背景色と波形だけを透過し、人物・枠・パネル・文字は残します。編集プレビューは市松模様で透過部分を示します。

保存先は従来のobsScenes/ルームID/本人UIDのまま、任意のBooleanフィールドtransparentBackgroundを追加します。未設定の既存レコードはfalseとして読み込み、以前の表示を維持します。保存者の権限は変更せず、型がBoolean以外の値は拒否します。画像の新規アップロードや別の保存領域は追加しません。

本人のアイコン・名前・パートをhost-identityでまとめ、ルーム名の下の領域で中央配置し、少し下へ調整しました。本人欄・配信説明欄の縦幅や、本人＋8名の構成は維持します。

検証: Chromiumの両テーマでチェック操作、保存・再読込、プレビュー固定、長文表示、9名表示を確認しました。表示ページ単体のPNGも取得し、背景のアルファ値が0、パネルは表示されることを確認しています。OBS Studio実機での確認は別途必要です。
