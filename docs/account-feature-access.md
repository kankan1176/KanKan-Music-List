# フレンド・ルームのGoogleログイン制限

- 左メニューの「フレンド」「ルーム」は、未ログイン・匿名ゲストには半透明で表示し、クリック時にGoogleログインの案内を表示します。無効ボタンにはせずキーボード操作も可能です。
- フレンド画面・検索・お気に入り操作、ルーム作成、ルームID入力による入室はGoogleログインが必要です。直接関数を呼んだ場合も入口を検査します。
- `?room=<ID>` の共有URLで既存ルームを開いた場合に限り、匿名認証で参加できます。入室後の参加名変更、予約・演奏確定・演奏完了、退室は維持します。
- Googleログアウト時はフレンド・ルーム作成画面を閉じ、操作途中に認証が変わった場合の新規作成やID入力による遷移を止めます。
- Firebaseでは、ルームおよびsettingsの新規作成をGoogle認証に制限する検証を既存ルールへ追加します。既存の書き込み許可、入力検証、参加者・キューの権限は保持します。
- フレンド関係の既存read/write許可にはGoogle認証条件を追加します。公開プロフィール・公開マイリスト・OBS表示の読み取りは変更しません。
- 共有URLと同じ `?room=<ID>` を手入力したURLは区別できません。共有URLを秘密の招待トークンとして検証する機能は追加していません。

検証: `node scripts/check-account-features.cjs` はルールの保持と冪等性を検証します。CIの `test-room-account-access.cjs` は本番から取得したルールに変更を合成し、ローカルのエミュレーターと合成データだけでGoogle作成・ゲスト作成拒否・共有ルーム内のゲスト演奏操作を確認してからルールを反映します。本番のルーム・楽曲・ユーザーデータは変更しません。
