# コードWikiの通常版・ベータ版

アカウント設定のスライドスイッチは左が通常、右がベータ版。初期値は通常。
`users/{uid}/preferences/chordwikiVersion` に `normal` または `beta` を保存する。
Googleアカウント本人だけが読み書きでき、未ログインでは通常版を使用する。
アカウント切り替え時は前ユーザーのリスナーを解除し、通常へリセットしてから新しい設定を取得する。
保存に失敗した場合は案内を表示する。公開マイリストも閲覧者本人の設定を適用する。

`chordwiki-version.js` が公式ホストだけを許可し、選択に合わせて `ja.chordwiki.org` / `beta.chordwiki.org` を切り替える。
全曲一覧・詳細・マイリスト・共有ページ・ルーム内リンクに適用する。
移調のKey・日本語・空白とプラス記号を維持する。右メニューのボタンはクリック時に最新設定を取得する。
楽曲マスターの通常URL・個人Key・公開共有データはバージョン選択で書き換えない。
