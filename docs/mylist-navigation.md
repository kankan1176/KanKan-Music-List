# マイリストの導線統合

左メニューの「マイリスト」は新しいマイリストページ（mylist.html#mine）を新規タブで開きます。Googleログイン本人の保存済み楽曲・Key・パート・外観を読み込み、公開停止中でも本人は自分の一覧を確認できます。ゲストにはログインの案内を表示します。

重複していた「マイリスト共有」メニューは削除し、「マイリストサイト編集」は「マイリストUI編集」へ改称しました。公開／停止スイッチ、公開URLのコピー、配色・背景の保存はUI編集画面に残しています。既存の公開URLは変更しません。

楽曲の追加・削除、Key・パート変更、クリップボード一括登録等の既存機能は、新しいマイリストページの「楽曲登録・編集」（/?view=mylist-edit）から利用できます。この明示的な編集用ルートは、メニューの閲覧用マイリストとは分けています。ルーム内の「自分」の曲一覧・共有同期も維持しています。

アイコンの編集場所は「アカウント設定」へ移しました。画像形式・400×400px・本人限定保存・上書き／削除の仕様と保存先は変更していません。データ移行やFirebaseルールの変更はありません。
