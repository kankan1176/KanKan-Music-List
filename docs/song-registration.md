# 新規楽曲追加の選択式分類

手動入力は曲名・アーティスト名・ChordWiki原曲URL（必須）、BPM（任意）、アニソン選択時のアニメ作品名（任意）。
空欄・空白だけの曲名とアーティスト名は送信不可。URL形式も検証する。
申請は従来どおりGoogleログインユーザーのみ、管理者承認後に公開する。

- ①基本ジャンル: J-POP / K-POP / 洋楽の単一選択。
- ②楽曲の分類: アニソン / ボカロ / Vtuber / ドラマ主題歌 / 映画主題歌 / ゲーム / アイドル / TVの複数選択。
- ③音楽ジャンル: 指定12種類を複数選択。
- ボカロ選択時: VOCALOID → CeVIO AI → Synthesizer V → UTAU → VOICEVOXの順に48項目を表示。複数選択可能。
- アニソン選択時: 少年漫画5種類・少女漫画8種類・その他「まんがタイムきらら」の単一選択。

UIの番号を既存列番号として扱わない。
①はgenre1、②のアニソン/ボカロ/Vtuber/ゲームはgenre2、ドラマ/映画/TVはgenre3、アイドルはgenre4、掲載媒体はgenre5、③の音楽ジャンルはgenre6、歌唱者はvocal_synthsへ振り分ける。
TVの保存値は既存マスターと同じ「TV（CM・バラエティ）主題歌」。複数値は「、」で結合。
分類を外して追加欄が非表示になった場合、その歌唱者・掲載媒体・アニメ作品名を送信しない。
同名の重音テト・波音リツは同じ歌唱者名として同期・重複排除する。ソフト名別の新しい列は作成しない。
選択式の分類項目は未選択でも送信可。年の手動欄はこのフォームから外す。アニメ作品名は従来のtieupへ保存する（240文字以内）。既存マスターの値は変更しない。

ソートマスタの公開スナップショットに「まんがタイムきらら」を追加し、既存のアニソン絞り込みにも表示。
スプレッドシートへの書き込みはこのフォーム変更では行っていない。次回のソートマスタ同期時にこの追加項目を維持する。

vocal_synthsは多数の歌唱者選択に対応するため、申請・マスター・共有表示・編集承認の上限を1000文字へ統一。
新規申請の作成時に3必須項目をFirebase側でも確認し、既存申請の確認・却下を妨げない。既存の読み書き権限は維持する。

検証: `node scripts/check-song-registration.cjs`、既存の分類/共有/権限/編集検査、架空データによる1920・834・390pxのブラウザ操作、production由来ルールのエミュレーター検証。

ボカロ別は全選択肢でボタン寸法を統一し、名称と括弧内の補足を分けて表示する。補足は小さくし、どちらも途中改行しない。ソフト間は12px以上空け、高さの低いPCではグループを2列に配置する。選択値とソフトの順序は変更しない。
